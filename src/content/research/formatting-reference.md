## Heading level two

Body paragraphs use the long-form size and line length. This one also shows an inline
[link to the about page](/about) inside a sentence.

### Heading level three

Inline code looks like `getPublishedResearch()` or a file path such as `src/content/research/`.

An unordered list:

- First item.
- Second item with `inline code` and a [link](/research).
- Third item.

An ordered list:

1. First step.
2. Second step.
3. Third step.

> A blockquote holds quoted text or a short aside. It keeps the long-form line length and the muted
> colour.

Indicators and addresses, defanged and kept to documentation ranges:

```text
example[.]com
192.0.2[.]10
hxxps://example[.]com/a/very/long/path/that/keeps/going/past/the/edge/of/a/narrow/screen/and/must/scroll/inside/its/own/box
```

Commands:

```bash
npm run dev
npm run build
```

A small table:

| Element | What it shows            |
| ------- | ------------------------ |
| `p`     | Body text                |
| `pre`   | `hxxps://example[.]com/` |
| `table` | Rows and columns         |
